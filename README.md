# Дополнительный волновой изгибающий момент — ПКПС РКО, п. 2.2.10

Веб-приложение для расчёта Mдв, Nдв и построения эпюр (классы «М», «О», «Р», «Л»).

## Запуск в VS Code

1. Откройте папку проекта в VS Code (File → Open Folder).
2. Откройте терминал (Ctrl+`) и создайте окружение:

   Windows:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```
   macOS / Linux:
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   ```
3. Установите зависимости и запустите:
   ```
   pip install -r requirements.txt
   streamlit run app.py
   ```
   Браузер откроется на http://localhost:8501.

Чтобы дать доступ другим людям в локальной сети: `streamlit run app.py --server.address 0.0.0.0`
(адрес для коллег: http://<ваш-IP>:8501). Для постоянного размещения в интернете подойдёт
Streamlit Community Cloud или любой сервер с Docker.

## Тесты

```
python -m unittest -v
```
Тесты сверяют формулы с таблицами Правил 2.2.10-2, 2.2.10-3 и 2.2.10-4 (все четыре класса),
проверяют логику kр, Mу, эпюры и ввод данных.

## Файлы

| Файл | Назначение |
|---|---|
| `pkps_core.py` | формулы Правил и расчёт (без интерфейса) |
| `pkps_plots.py` | эпюры Mдв, Nдв, Mр (matplotlib) |
| `app.py` | веб-интерфейс Streamlit |
| `test_pkps_core.py` | тесты |

## Единицы

L, B, T, Tн — м; **V₀ — км/ч** (в интерфейсе можно м/с и узлы); I — м⁴; D — кН; моменты — кН·м.

## Границы этой версии

Не реализованы: п. 2.2.11 (классы «М-СП», «М-ПР», «О-ПР»), п. 2.2.15, расчёт Mтв.
Расчёт справочный; соответствие Правилам подтверждает расчётчик и РКО.
